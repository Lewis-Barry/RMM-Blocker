How to use

  1. Find each remote tool your team uses, then tick Exclude.
  2. Download the XML and deploy it as a WDAC policy, e.g. through Intune.
  3. Optional: turn on Include IOC exports and import every CSV batch into Defender indicators.
  4. Pilot on one test device before a wider rollout.

          KQL for network discovery

          Run in Microsoft Defender > Advanced hunting to find endpoints that contacted a LOLRMM domain or IP.

          Is this perfect?

          No. This policy matches tools by expected file name and path, not by file hash or publisher signature. Renamed copies or tools run from unexpected folders can get past it, and legitimate copies in other locations may be blocked.

          Pair it with the Defender IOCs. Even if a tool launches, it won't be able to connect.

          Most RMM abuse uses legitimate tools the expected way, which these rules can't tell apart from your own use. Treat this as one layer and test on pilot devices first.
