How to block Datto RMM / Autotask with Intune and Defender

To block Datto RMM / Autotask, deploy an App Control for Business (WDAC) policy in Intune that denies its 3 file paths and import its 121 domains as Microsoft Defender block indicators. RMM Guard blocks it by default and generates the files, free. Policy 1.0.0.22.

Build a policy that blocks Datto RMM / Autotask

Which files does Datto RMM / Autotask run from on Windows?

The policy denies these paths. Deploy it in Intune under Endpoint security → App Control for Business. Step-by-step guide.

  • *\centrastage\*
  • *\AEMAgent*.exe
  • *\CagService*.exe

If you use Datto RMM / Autotask

Tick Exclude next to Datto RMM / Autotask in the builder before you export. Its rules are left out of every file.

Can Datto RMM / Autotask get past the block?

The Windows rules match by file name and path, not by hash or signature, so a renamed copy can. The Defender indicators still block its network connections, which is why the two are used together.
