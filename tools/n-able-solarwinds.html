How to block N-able / SolarWinds with Intune and Defender

To block N-able / SolarWinds, deploy an App Control for Business (WDAC) policy in Intune that denies its 18 file paths and import its 29 domains as Microsoft Defender block indicators. RMM Guard blocks it by default and generates the files, free. Policy 1.0.0.22.

If you use N-able / SolarWinds

Tick Exclude next to N-able / SolarWinds in the builder before you export. Its rules are left out of every file.

Can N-able / SolarWinds get past the block?

The Windows rules match by file name and path, not by hash or signature, so a renamed copy can. The Defender indicators still block its network connections, which is why the two are used together.
