How to block Supremo with Intune and Defender

To block Supremo, deploy an App Control for Business (WDAC) policy in Intune that denies its 5 file paths, import its 1 domain as Microsoft Defender block indicators and on macOS deny Apple Team ID LL93ZLFYJ2. RMM Guard blocks it by default and generates the files, free. Policy 1.0.0.22.

Build a policy that blocks Supremo

Which files does Supremo run from on Windows?

The policy denies these paths. Deploy it in Intune under Endpoint security → App Control for Business. Step-by-step guide.

  • *\supremo\*
  • *\supremoservice*.exe
  • *\supremo*.exe
  • *\supremosystem*.exe
  • *\supremohelper*.exe

Which domains does Supremo connect to?

Block these in Microsoft Defender under Settings → Endpoints → Indicators. They apply to Windows and macOS devices. Import guide.

  • supremocontrol.com

How do I block Supremo on a Mac?

Deny its code signature in the Intune settings catalog. Needs macOS 27 and a supervised Mac. macOS guide.

If you use Supremo

Tick Exclude next to Supremo in the builder before you export. Its rules are left out of every file.

Can Supremo get past the block?

The Windows rules match by file name and path, not by hash or signature, so a renamed copy can. The Defender indicators still block its network connections, which is why the two are used together.
