How to block Chrome Remote Desktop with Intune and Defender

To block Chrome Remote Desktop, deploy an App Control for Business (WDAC) policy in Intune that denies its 5 file paths, import its 5 domains as Microsoft Defender block indicators and on macOS deny Apple Team ID EQHXZ8M8AV. RMM Guard blocks it by default and generates the files, free. Policy 1.0.0.22.

Build a policy that blocks Chrome Remote Desktop

Which files does Chrome Remote Desktop run from on Windows?

The policy denies these paths. Deploy it in Intune under Endpoint security → App Control for Business. Step-by-step guide.

  • *\google\chrome remote desktop\*
  • *\remoting_host*.exe
  • *\remoting_native_messaging_host*.exe
  • *\remoting_desktop*.exe
  • *\remoting_assistance_host*.exe

Which domains does Chrome Remote Desktop connect to?

Block these in Microsoft Defender under Settings → Endpoints → Indicators. They apply to Windows and macOS devices. Import guide.

  • chromoting-client.talkgadget.google.com
  • chromoting-host.talkgadget.google.com
  • chromoting-oauth.talkgadget.google.com
  • remotedesktop-pa.googleapis.com
  • remotedesktop.google.com

How do I block Chrome Remote Desktop on a Mac?

Deny its code signature in the Intune settings catalog. Needs macOS 27 and a supervised Mac. macOS guide.

If you use Chrome Remote Desktop

Tick Exclude next to Chrome Remote Desktop in the builder before you export. Its rules are left out of every file.

Can Chrome Remote Desktop get past the block?

The Windows rules match by file name and path, not by hash or signature, so a renamed copy can. The Defender indicators still block its network connections, which is why the two are used together.
