How to block GoToAssist with Intune and Defender

To block GoToAssist, deploy an App Control for Business (WDAC) policy in Intune that denies its 6 file paths and import its 8 domains as Microsoft Defender block indicators. RMM Guard blocks it by default and generates the files, free. Policy 1.0.0.22.

Build a policy that blocks GoToAssist

Which files does GoToAssist run from on Windows?

The policy denies these paths. Deploy it in Intune under Endpoint security → App Control for Business. Step-by-step guide.

  • *\gotoassist remote support\*
  • *\gotoassist*.exe
  • *\GoTo Assist Opener*.exe
  • *\g2ax_comm_customer*.exe
  • *\g2ax_comm_expert*.exe
  • *\g2ax_service*.exe

Which domains does GoToAssist connect to?

Block these in Microsoft Defender under Settings → Endpoints → Indicators. They apply to Windows and macOS devices. Import guide.

  • cdn.getgo.com
  • desktopstreaming.com
  • fastsupport.com
  • gotoassist.at
  • gotoassist.com
  • gotoassist.me
  • helpme.net
  • goto.com

If you use GoToAssist

Tick Exclude next to GoToAssist in the builder before you export. Its rules are left out of every file.

Can GoToAssist get past the block?

The Windows rules match by file name and path, not by hash or signature, so a renamed copy can. The Defender indicators still block its network connections, which is why the two are used together.
