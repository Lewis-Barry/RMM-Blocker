How to block Total Software Deployment with Intune and Defender

To block Total Software Deployment, deploy an App Control for Business (WDAC) policy in Intune that denies its 2 file paths. RMM Guard blocks it by default and generates the files, free. Policy 1.0.0.22.

Build a policy that blocks Total Software Deployment

Which files does Total Software Deployment run from on Windows?

The policy denies these paths. Deploy it in Intune under Endpoint security → App Control for Business. Step-by-step guide.

  • *\Tsdservice*.exe
  • *\Total Software Deployment\*

If you use Total Software Deployment

Tick Exclude next to Total Software Deployment in the builder before you export. Its rules are left out of every file.

Can Total Software Deployment get past the block?

The Windows rules match by file name and path, not by hash or signature, so a renamed copy can. Treat the policy as one layer of defence.
